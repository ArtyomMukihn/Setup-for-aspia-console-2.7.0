# Aspia для macOS — Console и Launcher

Набор для подключения к удалённым компьютерам через Aspia с использованием адресных книг старого формата `.aab`.

- **Aspia Console 2.7.0** — открывает адресные книги `.aab` и позволяет запускать подключения.
- **Aspia Launcher** — небольшая утилита, которая создаёт файл `.command` для запуска Console с выбранной адресной книгой.

Aspia — сторонний проект. Этот репозиторий содержит вспомогательную утилиту и не является официальным репозиторием Aspia.

## Что скачать

Откройте раздел **Releases** этого репозитория и скачайте:

| Файл | Назначение |
| --- | --- |
| `aspia-console-2.7.0-x86_64.dmg` | Установщик Aspia Console для Mac с процессором Intel; на Apple Silicon используется Rosetta 2 |
| `Aspia-Launcher.zip` | Архив с приложением `Aspia Launcher.app` |

Адресная книга `.aab` в комплект не входит. Используйте свой файл.

## Установка

1. Откройте `aspia-console-2.7.0-x86_64.dmg`.
2. Переместите **Aspia Console.app** в папку **«Программы» / Applications**.
3. Распакуйте `Aspia-Launcher.zip` двойным щелчком.
4. Переместите **Aspia Launcher.app** в удобную папку, например «Программы».
5. На Mac с Apple Silicon, если macOS предложит установить Rosetta 2, выполните установку по подсказкам системы.

Launcher ожидает, что исполняемый файл Console находится по пути:

```text
/Applications/Aspia Console.app/Contents/MacOS/Aspia Console
```

## Создание файла запуска

1. Сохраните адресную книгу `.aab` в постоянную папку на своём Mac.
2. Запустите **Aspia Launcher.app**.
3. Выберите нужный файл `.aab`.
4. Укажите, куда сохранить файл `.command`, например на Рабочий стол.
5. Дождитесь сообщения «Готово!».

Теперь двойной щелчок по созданному `.command` запускает Aspia Console сразу с выбранной адресной книгой. Окно выбора адресной книги в самой Console для этого не требуется.

Если адресная книга защищена паролем, введите его в Aspia. Launcher не запрашивает пароль и не записывает его в файл запуска.

## Как это работает

Launcher записывает в `.command` команду такого вида и даёт файлу право запуска:

```sh
#!/bin/zsh
exec '/Applications/Aspia Console.app/Contents/MacOS/Aspia Console' '/путь/к/адресной книге.aab'
```

Пути с пробелами, кириллицей и одинарными кавычками обрабатываются автоматически. Файл `.aab` не копируется внутрь `.command`: в нём сохраняется только путь к адресной книге.

## Перенос на другой Mac

1. Установите Aspia Console на другом Mac.
2. Передайте туда **Aspia Launcher.app** и нужную адресную книгу `.aab`.
3. Запустите Launcher на этом Mac и создайте новый `.command`.

Готовый `.command` содержит полный путь к файлу, включая имя пользователя и папки. Поэтому на другом компьютере его лучше создать заново. Если переместить или переименовать `.aab`, также создайте новый файл запуска.

## Решение проблем

### В Console кнопка Open address book ничего не открывает

Создайте `.command` через Aspia Launcher. Он передаёт путь к адресной книге непосредственно при запуске Console.

### Launcher сообщает, что Aspia Console не найдена

Проверьте, что **Aspia Console.app** находится непосредственно в папке `/Applications`, а название приложения не изменено. Приложение **Aspia Client** не заменяет Console для этого Launcher.

### После перемещения адресной книги запуск перестал работать

Запустите Launcher и выберите файл по новому пути. Сохраните новый `.command`.

### При запуске открывается Терминал

Это ожидаемое поведение: macOS выполняет файлы `.command` через Терминал.

### macOS предупреждает о приложении

Aspia Launcher — локально собранная утилита без нотариального заверения Apple. На другом Mac система может ограничить её запуск. Ознакомьтесь с сообщением macOS и проверяйте источник скачанных файлов; отключать системную защиту для работы утилиты не требуется.

### macOS предупреждает о версии для Intel

В комплекте используется версия Console для Intel. На Apple Silicon она работает через Rosetta 2. Совместимость с будущими версиями macOS не гарантируется.

## Конфиденциальность

Адресная книга `.aab` может содержать адреса компьютеров и сохранённые данные подключения. Не публикуйте личные адресные книги в открытом репозитории и передавайте их только доверенным людям.

Сгенерированный `.command` содержит локальный путь к адресной книге, но не её содержимое.
